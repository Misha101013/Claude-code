Как выложить сайт с телефона

  1. Откройте репозиторий на GitHub в браузере телефона или в приложении GitHub.
  2. Settings → Pages → Source: GitHub Actions — включается один раз.
  3. Любой коммит в основную ветку публикует сайт автоматически (workflow уже лежит в репозитории).
  4. Адрес вида https://ИМЯ.github.io/РЕПО/ появится там же, на вкладке Pages.

Всё бесплатно: GitHub Pages для статики, без базы данных и без бэкенда.
