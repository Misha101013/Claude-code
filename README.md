# CutDesk — заявки на видео + аналитика для монтажёров

Статический сайт: клиент отправляет бриф за минуту, эдитор ведёт заявки и смотрит
графики по студии. Без сервера, без базы данных, без подписок — только файлы,
которые GitHub Pages раздаёт бесплатно.

## Что внутри

- **Заявка** — бриф с быстрыми пресетами (Reels, YouTube, реклама, свадьба,
  подкаст). Пресет сразу проставляет тип, площадку, хронометраж, часы и состав
  работ, остаётся вписать клиента и дедлайн.
- **Отправка без бэкенда** — готовая заявка уходит в Telegram, письмом или
  ссылкой. В ссылке лежит вся заявка целиком: эдитор открывает её и добавляет в
  свою базу одним нажатием.
- **Заявки** — список с фильтрами по статусу, поиском, сортировкой по дедлайну и
  бюджету, отметкой просрочек, сменой статуса и редактированием.
- **Аналитика** — выручка периода крупной цифрой, четыре плитки со спарклайнами
  и графики: динамика (заявки / выручка / часы, линия или столбцы), типы видео
  по периодам, воронка стадий, топ клиентов, загрузка по дням недели. У каждого
  графика есть подсказка при наведении, работа с клавиатуры и таблица-двойник.
- **Данные** — всё в `localStorage` браузера, плюс экспорт и импорт JSON и набор
  демо-данных, чтобы сразу посмотреть, как выглядят графики.

Тёмная и светлая темы. Палитра графиков проверена на цветовую слепоту и на
контраст к фону в обоих режимах.

## Как выложить сайт с телефона

1. Откройте репозиторий на GitHub (браузер или приложение GitHub).
2. **Settings → Pages → Source: GitHub Actions** — включается один раз.
3. Всё. Любой коммит в ветку публикует сайт: workflow
   `.github/workflows/deploy.yml` уже лежит в репозитории и собирать ничего не
   нужно.
4. Адрес вида `https://ИМЯ.github.io/РЕПО/` появится на вкладке **Actions** и на
   той же странице **Pages**.

Дальше правки тоже можно делать с телефона: открыть файл на GitHub, карандаш,
Commit — через минуту сайт обновится.

## Локальный запуск

Файлы подключены как ES-модули, поэтому нужен http, а не открытие `index.html`
двойным щелчком:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Структура

```
index.html          разметка всех четырёх экранов
assets/style.css    оформление и токены цвета (светлая/тёмная тема)
assets/data.js      модель заявки, хранилище, агрегации, демо-данные
assets/charts.js    графики на чистом SVG: линия, столбцы, стопка, полосы
assets/app.js       маршруты, формы, доска заявок, аналитика
```

## Настройки

На вкладке «Настройки» задаются название студии, Telegram и почта для заявок,
валюта и ставка за час. Там же экспорт и импорт базы — сделайте выгрузку, если
собираетесь чистить браузер: данные хранятся только на устройстве.
