# Ротоскоп — покадровая анимация по видео

Веб-приложение для рисованной анимации поверх видео (ротоскопирование), по образцу FlipaClip.
Загружаете ролик, нарезаете его на кадры, обводите каждый кадр — и получаете GIF или набор PNG.

**Всё работает прямо в браузере.** Нет ни сервера, ни загрузки файлов куда-либо: видео читается
локально, кадры и рисунки живут в памяти вкладки. Приложение можно бесплатно захостить как
статику — на GitHub Pages, Netlify или любом другом хостинге.

## Как пользоваться

1. **Видео.** Выберите файл (MP4, WEBM, MOV) кнопкой или перетащите его в окно. Появятся превью,
   длительность и размер кадра. Для начала хватит ролика на 3–15 секунд.
2. **Кадры.** Выберите FPS — пресеты 8 / 12 / 14 / 24 или точное значение от 1 до 30. Приложение
   покажет, сколько кадров получится, и нарежет видео с прогресс-баром. Все кадры появятся лентой
   миниатюр внизу.
3. **Рисование.** Кадр видео виден как фон (его прозрачность регулируется), поверх — отдельный
   прозрачный слой для рисунка. У каждого кадра свой рисунок.
4. **Просмотр и экспорт.** Кнопка ▶ проигрывает анимацию с выбранным FPS, кнопка ⬇ сохраняет
   результат как GIF или как ZIP с PNG-кадрами.

## Возможности

- Нарезка видео на кадры с произвольным FPS (1–30), с прогрессом и оценкой оставшегося времени
- Кисть с настройкой толщины и цвета, ластик, отмена/возврат — на каждом кадре независимо
- Рисование пальцем, стилусом и мышью (Pointer Events); нажим стилуса меняет толщину линии,
  касания ладонью отсекаются, пока рисуют пером
- Онион-скин — полупрозрачный предыдущий кадр под рукой
- Регулировка прозрачности видео-подложки, чтобы удобнее было обводить
- Копирование рисунка с предыдущего кадра — быстрый старт для похожих кадров
- Просмотр анимации с выбранным FPS, с видео-подложкой или без неё
- Экспорт в анимированный GIF (собирается в браузере) или в ZIP с прозрачными PNG
- Адаптивный интерфейс: крупные кнопки, вертикальная раскладка на телефоне, плавающая панель
  инструментов на десктопе

### Горячие клавиши (на компьютере)

| Клавиша | Действие |
| --- | --- |
| `←` / `→` | предыдущий / следующий кадр |
| `B` / `E` | кисть / ластик |
| `O` | онион-скин |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / вернуть |

## Запуск

Нужен любой статический сервер — просто открыть `index.html` через `file://` не получится,
браузер не даст читать видео из canvas.

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

### Хостинг на GitHub Pages

Settings → Pages → Source: ветка с этими файлами, папка `/ (root)`. Сборка не нужна — это
статический HTML/CSS/JS.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка трёх экранов, окон просмотра и экспорта |
| `css/style.css` | оформление, mobile-first |
| `js/app.js` | нарезка видео, слои рисования, навигация по кадрам, просмотр, экспорт |
| `js/gif.js` | кодировщик анимированного GIF89a: медианное сечение палитры + LZW |
| `js/zip.js` | сборка ZIP-архива (метод «store» + CRC32) |

Внешних библиотек нет вообще — GIF и ZIP собираются собственным кодом.

Несколько технических решений, которые стоит знать:

- **Кадры видео** извлекаются перемоткой `<video>` по `currentTime` с ожиданием события `seeked`
  и отрисовкой в `<canvas>`. Кадр хранится как JPEG в Blob URL, декодированные картинки держатся
  в LRU-кэше на 14 штук — иначе на длинных нарезках телефону не хватит памяти.
- **Рисунок хранится векторно** — списком штрихов с нормализованными координатами, а не растром.
  Поэтому отмена бесплатна, память расходуется экономно, а экспорт можно делать в любом размере.
- **Ничего не пишется в `localStorage`/`sessionStorage`** — состояние живёт только в памяти на
  время сессии. Если закрыть вкладку, работа пропадёт (браузер предупредит об этом).
- **Длинные кадры**: сторона рабочего кадра ограничена 1024 px, а количество кадров — 600.

## Ограничения

- Читаются только те форматы видео, которые умеет сам браузер. На практике MP4 (H.264) и WEBM
  работают везде, MOV — если внутри H.264. Некоторые записи с камеры (HEVC) Chrome не откроет.
- GIF-палитра ограничена 256 цветами — для обводки этого достаточно, но фотографический фон
  в режиме «рисунок поверх видео» может слегка потерять в цветах.
- Экспорт GIF на длинной анимации занимает время: вся работа идёт в одном потоке браузера.
