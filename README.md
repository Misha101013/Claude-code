# 🛒 Маркет Тайкун — 3D мультиплеерный симулятор супермаркета

Браузерная игра в духе **Supermarket Simulator**, но **в полном 3D от первого лица** и
**с кооперативным мультиплеером**: несколько игроков заходят в один магазин и
управляют им вместе — один разгружает фуру, второй выкладывает товар, третий стоит на кассе.

Никаких плагинов и загрузок: открыл ссылку, ввёл имя и код магазина — и ты в смене.

---

## Быстрый старт

```bash
npm install
npm start
# открыть http://localhost:3000
```

Чтобы играть вдвоём — второй игрок открывает тот же адрес и вводит **тот же код магазина**.
В локальной сети: `http://<ip-хоста>:3000`. Порт меняется через `PORT=8080 npm start`.

## Что есть в игре

### Полный цикл ритейла
| Этап | Как это работает |
|---|---|
| 📦 **Закупка** | Ноутбук на складе: 35 товаров в 8 категориях, цена за коробку, доставка ~40 сек. |
| 🚚 **Разгрузка** | Фура сбрасывает коробки в жёлтую зону склада. |
| 🗄️ **Выкладка** | Берёшь коробку (`E`), несёшь к стеллажу, удерживаешь `E` — товар едет на полку по одной штуке. |
| 🏷️ **Ценообразование** | Цена на каждый товар выставляется вручную. Дороже рынка — покупатели отказываются и роняют рейтинг, дешевле — сметают всё, но маржа падает. |
| 🔌 **Открытие** | Рубильник у входа переключает вывеску ОТКРЫТО/ЗАКРЫТО. |
| 🧾 **Касса** | Покупатель выкладывает товар на ленту, ты пробиваешь позиции (`E`, можно удерживать) и принимаешь оплату. |
| 📈 **Развитие** | Опыт → уровни → новые товары. Деньги → новые стеллажи, кассы, наёмные кассиры. |
| 🌙 **Конец дня** | Аренда и зарплаты списываются, показывается отчёт: выручка, расходы, прибыль. |

### Мультиплеер
- Общая экономика: деньги, склад, полки и рейтинг — одни на всех.
- Видно других игроков (модель, ник, коробка в руках) и всё, что они делают.
- Чат (`T`) и список смены.
- Комнаты по коду: `MAIN`, `ALPHA`, что угодно — каждый код это отдельный магазин.
- Прогресс магазина сохраняется на диск и переживает перезапуск сервера.

### Чего не было в оригинале
- Полноценный кооператив в браузере без установки.
- Мини-карта с состоянием полок (зелёная — полная, оранжевая — заканчивается, красная — пустая).
- Подсказка «что делать дальше» в HUD — вместо чтения гайдов.
- Наёмный кассир, который сам пробивает чеки, пока вы работаете в зале.
- Живой список активных магазинов на старте.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | ходьба |
| `Shift` | бег |
| мышь | обзор (клик по экрану — захват курсора) |
| `E` | взять коробку / выложить товар (удерживать) / пробить чек / принять оплату / рубильник |
| `F` | бросить коробку |
| `Tab` | ноутбук управления (у стола на складе) |
| `T` | чат |
| `M` | показать/скрыть карту |
| `Esc` | меню / закрыть ноутбук |

## Как играть (первые 5 минут)

1. Спавн на складе. Иди к столу с ноутбуком (`Tab`).
2. Вкладка **Заказ** — набери по 2–3 коробки дешёвых ходовых товаров (бананы, молоко, хлеб, вода, чипсы). **Заказать**.
3. Ждёшь фуру ~40 секунд, коробки появляются в жёлтой зоне.
4. `E` на коробке → идёшь к стеллажу → удерживаешь `E`, пока товар не выложится.
5. Пустую коробку сдай в бак на складе (`E`) — вернут пару центов.
6. Проверь цены (ноутбук → **Цены**). Рыночная цена = 100% спроса, выше — спрос падает.
7. Иди к входу, `E` на рубильнике — магазин открыт.
8. Встань за кассу (зелёный круг) и пробивай покупателей.
9. Когда наторговал — закрой магазин рубильником, дождись, пока все уйдут, и закрой день в ноутбуке (**Отчёт**).

## Архитектура

```
shared/      общий код клиента и сервера (конфиг, товары, геометрия магазина, физика)
server/      авторитетная симуляция: index.js (HTTP+WS), room.js (магазин), nav.js (A* покупателей)
public/      клиент: three.js сцена, интерфейс, звук, сеть
tools/       simulate.mjs (прогон дня без клиента), e2e.mjs (тест в headless-браузере)
```

- **Сервер авторитетен** по всему, что влияет на экономику: деньги, полки, коробки, покупатели,
  кассы. Клиент шлёт только намерения (`взять коробку`, `пробить`, `заказать`) и свою позицию.
- Тик симуляции 20 Гц, снапшоты 12 Гц, позиции сглаживаются интерполяцией на клиенте.
- Покупатели ходят по графу путевых точек (A*), который строится из той же геометрии,
  что и коллизии, — так что клиент и сервер никогда не расходятся в планировке.
- Вся графика и звук генерируются в рантайме (canvas-текстуры, WebAudio) — внешних ассетов нет.

### Инструменты разработки

```bash
node tools/simulate.mjs                 # быстрый прогон целого дня в консоли
npx playwright install chromium         # один раз, для e2e
node tools/e2e.mjs                      # полный цикл в headless-браузере со скриншотами
```
