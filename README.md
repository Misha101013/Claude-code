# ⚔️ War of Wizards 2D

Онлайн-арена магов в 2D — открывается прямо в браузере телефона, без установки.
Вдохновлено War of Wizards, но полностью переосмыслено под 2D и сенсорное управление:
вид сверху, два виртуальных стика, быстрые матчи по 6 минут.

![стек](https://img.shields.io/badge/Node.js-18%2B-green) ![стек](https://img.shields.io/badge/WebSocket-ws-blue) ![стек](https://img.shields.io/badge/Canvas-2D-orange)

## Быстрый старт

```bash
npm install
npm start
# откройте http://localhost:3000
```

Чтобы поиграть с телефона в одной Wi-Fi сети, откройте `http://<IP-компьютера>:3000`.

## Что это за игра

Свободная схватка (deathmatch) до 12 магов на одной арене. Убийства приносят очки,
матч длится 6 минут или до 30 убийств у лидера. Между матчами — таблица результатов
и автоматический рестарт, выходить из боя не нужно.

- **Сервер авторитетный**: вся физика, урон и попадания считаются на сервере — читерить клиентом бессмысленно.
- **Боты-«духи»** автоматически добивают комнату до 4 бойцов, поэтому играть можно даже в одиночку.
- **Комнаты** создаются сами: как только в одной набирается 12 человек, следующая открывается автоматически.

## Управление

| Телефон | ПК |
|---|---|
| Левый стик (левая половина экрана) — движение | `WASD` / стрелки |
| Правый стик — прицел + автоатака | мышь — прицел, `ЛКМ` / `Space` — атака |
| Кнопки справа — способности | `Q`, `E` |
| Кнопка 💨 — рывок | `Shift` |
| Кнопка 📊 — таблица | `Tab` |
| Кнопка ☰ — меню | `Esc` |

В меню есть автоприцел (мягкое доворачивание к цели), режим для левшей
(стики меняются местами), отключение звука и тряски экрана.

## Школы магии

| Школа | HP | Скорость | Атака | Способность | Ультимейт |
|---|---|---|---|---|---|
| 🔥 **Пиромант** | 100 | 205 | Огненный шар (урон по площади) | Волна огня — веер из 7 снарядов | Метеор: 60 урона + поджог |
| ❄️ **Криомант** | 110 | 198 | Ледяная стрела (замедление) | Ледяная нова вокруг себя | Буран: 5 волн урона и заморозки |
| ⚡ **Буревестник** | 92 | 224 | Разряд (быстрый, прошивает одного) | Цепная молния на 4 цели | Штормовой рывок: +45% скорости, щит, ускоренные КД |

Школу можно сменить прямо в бою через меню — заклинания меняются сразу.

## Механики арены

- **Камни** блокируют и движение, и снаряды — за ними можно прятаться от цепной молнии.
- **Зелёные сферы** восстанавливают 35 HP, **синие** — 45 маны, respawn каждые 14 секунд.
- **Мана** регенерирует 11/сек: непрерывная стрельба постепенно осушает запас.
- **Защита на респауне** 1.5 сек снимается, как только вы сами атакуете.
- **Серия убийств** отображается в killfeed и в таблице.

## Архитектура

```
server/
  index.js            HTTP + WebSocket, статика, /api/config, /api/stats
  room.js             комнаты, матчмейкинг, тик 30 Гц, снапшоты 15 Гц, боты
  game/constants.js   весь баланс и карта в одном месте (часть уходит клиенту)
  game/world.js       симуляция: движение, снаряды, урон, пикапы, матч
  game/bot.js         ИИ: выбор цели, кайтинг, стрельба с упреждением
public/
  index.html          лобби + HUD
  css/style.css       мобильный интерфейс, safe-area, лендскейп
  js/net.js           WebSocket, буфер снапшотов, интерполяция 130 мс, реконнект
  js/input.js         виртуальные стики, клавиатура, мышь
  js/render.js        Canvas: камера, арена, маги, частицы, миникарта
  js/ui.js            лобби, HUD, таблица, меню, итоги
  js/main.js          игровой цикл, предсказание движения, автоприцел
```

**Сеть.** Клиент шлёт только намерения (`in` — вектор движения и угол, `cast` — слот
заклинания) 20 раз в секунду. Сервер отвечает снапшотами 15 раз в секунду в виде
компактных массивов чисел. Клиент рендерит мир с задержкой 130 мс и интерполирует
между снапшотами, а своего мага предсказывает локально и мягко подтягивает к
серверной позиции — управление ощущается мгновенным даже на мобильной сети.

**Защита.** Ограничение 200 сообщений в секунду с клиента, `maxPayload` 4 КБ,
проверка типов входящих значений, heartbeat-пинг раз в 20 секунд убирает «мёртвые»
соединения, имена экранируются при выводе в HTML.

## Настройка через переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | порт HTTP/WebSocket |
| `MATCH_DURATION` | `360` | длительность матча в секундах |
| `MATCH_SCORE_LIMIT` | `30` | убийств до досрочного конца |
| `MATCH_INTERMISSION` | `12` | пауза с таблицей между матчами |

Баланс, карта и заклинания правятся в одном файле — `server/game/constants.js`.
Клиент получает оттуда же конфиг, так что дублировать числа не нужно.

## Деплой

Подойдёт любой хостинг Node.js с поддержкой WebSocket (Render, Railway, Fly.io, VPS).
Нужен `npm install && npm start`; при работе за обратным прокси включите
проксирование `Upgrade`/`Connection` для пути `/ws`. HTTPS-страница автоматически
использует `wss://`.
