# Сайт кофейни «Сфера» (Астана)

Одностраничный сайт кофейни «Сфера» — ул. Жошы хан, 16/1, Астана.
Сделан в фирменном стиле заведения: глубокий фиолетовый, жёлтые сердечки,
тёплое дерево и зелень из интерьера.

## Запуск

Отдельной сборки не требуется — это статический сайт.

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Или просто откройте `index.html` в браузере.

## Структура

```
index.html            — разметка всех секций
assets/css/styles.css — стили, фирменная палитра, адаптив
assets/js/main.js     — меню-бургер, табы меню, анимации появления
```

## Технические детали

- Без зависимостей и сборщиков: чистый HTML + CSS + JS.
- Шрифты — Google Fonts (Montserrat, Manrope) с системными фолбэками.
- Иллюстрации — inline SVG, внешних картинок нет, сайт грузится мгновенно.
- Адаптив: 1440 / 1024 / 880 / 620 / 420 px.
- Доступность: семантические теги, ARIA-табы с управлением стрелками,
  skip-link, видимый фокус, поддержка `prefers-reduced-motion`.
- SEO: мета-теги, Open Graph и микроразметка Schema.org `CafeOrCoffeeShop`.
- Отдельные стили для печати — меню можно распечатать одной страницей.
