# Слейся — party-игра в прятки на фото

Загрузи фото, спрячь своего персонажа, закрасив его кистями в тон фона
(с пипеткой!), а друзья пусть попробуют тебя найти. Работает прямо в
браузере телефона, без установки.

## Как играть

1. Один игрок нажимает **«Создать комнату»** и получает короткий код.
2. Остальные вводят этот код и жмут **«Войти»**. Нужно минимум двое.
3. Хост выбирает фото раунда — своё или готовую сцену — и жмёт
   **«Начать раунд»**.
4. Все, кроме искателя, ставят персонажа на фото и закрашивают его под
   фон: кисти (включая палец — тянет и смешивает уже нанесённые цвета
   в градиент, как в ibisPaint), пипетка прямо с фото, цветовое колесо,
   зум двумя пальцами, зажатый «глаз» показывает результат глазами
   искателя. Если в настройках включена «Подсказка фона» — раз за
   раунд можно волшебной палочкой приблизительно подсветить фон в
   небольшом круге (неточно, только для затравки).
   Пока ждёшь своей очереди прятаться (или уже спрятался и ждёшь
   остальных) — на экране виден таймер до конца пряток. Если в
   настройках включено «Видно других прячущихся», по мере того как
   остальные заканчивают, их места полупрозрачно появляются на твоём
   фото — чтобы не залезть в один и тот же угол. Искателю это никогда
   не показывается.
5. Искатель тапает по фото. Попыток ограниченное число — промах их
   тратит. Если долго никого не находит, включаются подсказки.
6. Раунд заканчивается, когда найдены все, кончились попытки или вышло
   время. Показываем, кто где прятался, и разбор очков.
7. Искатель меняется каждый раунд — по умолчанию каждый успевает
   поискать один раз. Побеждает лучшая сумма за матч.

## Очки

Роли сбалансированы на сопоставимые диапазоны, а матч по умолчанию
длится столько раундов, сколько игроков, — поэтому «чаще искать» не
может стать выигрышной стратегией.

**Прячущийся:** до 100 за прожитые секунды, +50 если не нашли вообще,
до 60 за качество маскировки. Качество считается честно — попиксельным
сравнением закрашенного персонажа с фоном под ним, поэтому просто
забиться в тёмный угол недостаточно.

**Искатель:** 60–120 за каждого найденного (чем быстрее, тем больше),
усреднённо по числу прячущихся, +40 если нашёл всех, плюс до 40 за
сэкономленные попытки.

## Настройки

В меню → «Настройки» можно поменять: число раундов, время на прятки и
поиск, число попыток у искателя, размер персонажа, подсказки, счётчик
маскировки, разовую подсказку фона, видимость других прячущихся и
звук. Правила матча задаёт тот, кто создаёт комнату — остальным они
прилетают автоматически.

## Технологии

Чистый HTML/CSS/JS без сборки — папку можно деплоить как есть.
Комнаты работают через прямое P2P-соединение между телефонами
([PeerJS](https://peerjs.com/), публичный бесплатный signaling-сервер,
без своего бэкенда). Хост — это «хаб»: все данные раунда (фото,
раскрашенные персонажи, попадания) идут через него остальным игрокам.

## Деплой на Netlify

Никакой сборки не требуется.

1. В Netlify: **Add new site → Import an existing project**, подключи
   этот репозиторий/ветку.
2. Build command оставь пустым, Publish directory — `.` (корень).
   Файл `netlify.toml` уже это настраивает.
3. Деплой — и ссылку можно скидывать друзьям.

Либо через Netlify CLI из корня проекта:

```bash
npx netlify-cli deploy --prod
```

## Важные ограничения (честно)

- **Все игроки должны быть онлайн одновременно** — состояние комнаты
  нигде не сохраняется, это не сервер с базой данных, а прямое
  соединение между открытыми вкладками/браузерами. Кратковременные
  обрывы (сел экран, открылась галерея за фото, скакнула сеть) не
  страшны — игрок автоматически переподключается в течение ~7 секунд,
  сверху виден лёгкий баннер «переподключаемся». Дольше — место в
  комнате освобождается, и об этом честно сообщают.
- Если во время раунда хост закрывает вкладку насовсем — комната
  закрывается (хост — единственный хаб). Обычные игроки могут
  выходить/заходить без этой проблемы.
- Подключение к комнате **после того как раунд уже начался** пока не
  поддерживается — заходить нужно ещё в лобби.
- Некоторые мобильные операторы/сети со строгим NAT/файрволом могут
  мешать прямому P2P-соединению между двумя конкретными телефонами
  (редко, но бывает). Обычный Wi-Fi/LTE — без проблем.

## Структура проекта

```
index.html           разметка всех экранов
styles.css           дизайн (тёмная «студия художника»)
js/main.js           связывает всё в кучу, работа с DOM
js/game.js           состояние матча и подсчёт очков (решает хост)
js/net.js            P2P-слой на PeerJS: звезда (хост — хаб) + авто-
                     переподключение при обрыве связи
js/settings.js       настройки матча и игрока + сохранение
js/paint-engine.js   канвас-движок: кисти, пипетка, экспорт спрайта
js/zoom.js           жесты: один палец рисует, два — зумят
js/blend.js          попиксельная оценка качества маскировки
js/shapes.js         силуэты персонажей (кот, хамелеон, зайчик, человечек)
js/color-wheel.js    HSV-колесо выбора цвета
js/audio.js          звуки, сгенерированные через WebAudio (без файлов)
js/palette-data.js   цвета аватаров
js/demo-scenes.js    процедурные демо-фоны (если лень грузить фото)
```
