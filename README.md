# Парсер заказов на сайты в Telegram (Казахстан)

Бот следит за Telegram и находит **заказы на разработку сайтов в Казахстане**:
лендинги, интернет-магазины, корпоративные сайты, доработки. Реклама веб-студий,
резюме, вакансии и спам отсеиваются, готовые лиды приходят вам в личку карточкой
с бюджетом, городом, контактами и ссылкой на исходное сообщение.

```
🔥 Лид 84/100 · лендинг
💰 300 000 ₸ · 📍 Астана · ⚡ срочно
💬 Фриланс Алматы · Telegram
👤 @owner · Айдос

  Нужен лендинг для кофейни в Астане, бюджет 300 000 тг, срочно

⚙️ topic: лендинг; intent: нужен, бюджет; geo: астана; urgency: срочно
[🔗 Открыть] [✅ В работу] [🗑 Мусор] [⛔ Бан автора] [🔕 Бан чата]
```

## Как это устроено

Две части работают в одном процессе:

| Часть | Что делает |
|---|---|
| **Юзербот (Telethon)** | Читает сообщения. Видит всё, что видит ваш аккаунт: любые группы и каналы, куда вы вступили. Обычный бот так не умеет — в чужие чаты его не пустят. |
| **Бот (aiogram)** | Присылает вам лиды и принимает команды: статистика, пороги, ключевые слова, чёрные списки. |

Путь сообщения: **сбор → нормализация → правила → [ИИ] → антидубли → карточка**.

1. **Сбор.** Живой поток из всех чатов, догон истории за последние дни при
   старте и глобальный поиск по Telegram по ключевым фразам (находит заказы даже
   в чатах, где вас нет). Плюс внешние биржи, если включите.
2. **Нормализация.** «с а й т», «са**йт», «cайт» латиницей, невидимые символы,
   эмодзи — всё приводится к одному виду, иначе фильтры обходятся тривиально.
3. **Правила.** Тематика, признаки спроса («нужен», «ищу», «кто сделает»),
   анти-признаки предложения («делаем сайты», «портфолио», «наша студия»),
   Казахстан, бюджет, срочность, контакты → оценка 0–100 и разобранные поля.
   Отличать спрос от предложения — главная задача: в чатах фрилансеров рекламы
   на порядок больше, чем заказов.
4. **ИИ (Gemini).** Вызывается только для спорных сообщений (серая зона по
   очкам) — точность растёт, а токенов тратится мало. Без ключа всё работает
   на правилах.
5. **Антидубли.** Один заказ, разосланный в десять чатов, придёт один раз:
   точный отпечаток плюс simhash ловит и переформулировки.

## Быстрый старт

```bash
git clone <репозиторий> && cd <репозиторий>
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # заполнить ключи
cp config.example.yaml config.yaml   # при желании — правила под себя

python -m app
```

При первом запуске Telegram пришлёт код подтверждения — введите его в консоли.
Сессия сохранится в `data/`, дальше вход будет автоматическим.

### Что нужно заполнить в `.env`

| Переменная | Где взять |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | https://my.telegram.org → API development tools |
| `TG_PHONE` | номер аккаунта, которым парсим (лучше отдельный) |
| `TG_PASSWORD` | пароль 2FA, если включён |
| `BOT_TOKEN` | @BotFather → /newbot |
| `OWNER_ID` | ваш user id, узнать у @userinfobot |
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey (необязательно) |

После запуска **напишите своему боту `/start`** — иначе Telegram не даст ему
отправлять вам сообщения.

### Что делать дальше

Юзербот видит только те чаты, куда вступил ваш аккаунт. Вступите в
казахстанские чаты фриланса, IT и бизнес-сообщества — чем их больше, тем больше
лидов. Через пару дней посмотрите `/chats`: там видно, какие чаты реально
приносят заказы, а какие только шумят.

## Проверка без Telegram

```bash
# прогон по тестовым сообщениям: видно решение и вклад каждого правила
python -m app --dry-run --file tests/fixtures/messages.jsonl

# свои сообщения: текстовый файл, блоки разделены строкой ---
python -m app --dry-run --file my_messages.txt -v

pytest    # тесты правил, антидублей, бюджета и разбора ответа Gemini
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/stats` | лиды за сутки/неделю, на чём отсеиваются сообщения, расход ИИ |
| `/check <текст>` | прогнать любой текст через фильтры и увидеть решение с объяснением |
| `/threshold 60` | порог отправки лида (по умолчанию 50) |
| `/ai off\|grey_zone\|all`, `/ai model …`, `/ai limit 500` | режим и лимиты ИИ |
| `/keywords list intent`, `/keywords add stop казино` | правки правил на лету |
| `/sources`, `/sources external on`, `/sources global off`, `/sources scan` | источники |
| `/chats` | какие чаты приносят лиды |
| `/bans`, `/unban chat <id>` | чёрные списки |
| `/export 30` | выгрузка лидов в CSV |
| `/pause`, `/resume`, `/reload` | пауза и перечитывание `config.yaml` |

Любое сообщение боту без команды прогоняется как `/check` — удобно проверять
формулировки.

Кнопки под карточкой (**В работу / Мусор / Бан автора / Бан чата**) не просто
убирают лид: они копятся в статистике чатов, и по `/chats` видно, откуда идёт
польза, а откуда мусор.

## Настройка качества

Всё, что влияет на отбор, лежит в `config.yaml`:

* `rules.topic` — о чём заказ (сайт, лендинг, магазин, WordPress…);
* `rules.intent` — признаки спроса;
* `rules.offer_anti` — признаки рекламы услуг (снимают очки);
* `rules.geo` / `rules.foreign` — Казахстан и «чужая» география;
* `rules.stop` — жёсткие стоп-слова (курсы, крипта, казино);
* `rules.weights` — вес каждой группы;
* `scoring.notify_threshold` — порог отправки, `scoring.ai_low/ai_high` — серая
  зона для ИИ.

Слишком много мусора → поднимите `notify_threshold` или добавьте фразу в
`offer_anti`. Пропускает заказы → опустите порог, добавьте формулировку в
`intent`. Проверять правки удобно командой `/check`.

### Внешние биржи

Выключены по умолчанию. `/sources external on` включает опрос kwork,
freelancehunt и olx.kz (список — в `config.yaml`, `external.sources`). Лиды
проходят через те же правила и тот же антидубль. Вёрстка сайтов меняется, так
что при ошибке источник просто пропускается — Telegram-поток не страдает.

## Docker

```bash
docker compose run --rm parser python -m app   # первый запуск: ввести код из Telegram
docker compose up -d                           # дальше в фоне
docker compose logs -f
```

`data/` монтируется томом: там сессия Telegram и база лидов.

## Важно про аккаунт

Парсинг идёт от имени вашего аккаунта. Telegram не любит агрессивную
автоматизацию: интервалы глобального поиска и бэкфилла по умолчанию
консервативные, снижать их не стоит. Используйте отдельный номер, а не тот, на
котором завязана переписка.

Данные не уходят никуда, кроме Telegram и (если включён ИИ) Gemini API. Секреты
живут в `.env`, база — в `data/leads.db`; оба в `.gitignore`.
